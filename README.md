# Pokémon Battle Theater

Buildless browser-based 3v3 Pokémon auto-battles, inspired by the user's supplied 2D sprite battle references. Run `npm start` and open http://127.0.0.1:4173. Run `npm run check` and `node test-engine.mjs` for checks.

36 featured Pokémon have bundled GIF/PNG sprites and stats. The searchable picker includes the first 1,025 species; additional Pokémon fetch their data from PokéAPI and sprites from PokeAPI/sprites. Downloaded Pokémon data is cached locally. Some later species only have static fallback sprites. Assets are attributed in the in-app credits. Online services and Google Fonts require connectivity; default teams and environments work without them.

Three overhead arenas evoke Indigo Stadium, Viridian Forest and Cinnabar using a flat 540×960 world, original tile layout, and texture/detail tiles from pret/pokeemerald. Battles use base stats, level-50-inspired damage, all 18 type matchups, STAB, random damage, 10% criticals, and 7% dodge chance. This is an intentionally simplified fan-made simulator, not the official battle rules. Pokémon can use a curated subset of their actual learned moves. Move pools include both physical and special attacks when supported, and avoid consecutive repeats. The previous actor sits out the next action. Species without a supported move use Struggle. A 180-turn limit prevents endless immunity matchups.

Version 2 presents top/bottom team HUDs, black move labels above attackers, close-combat multi-hit punches, kicks, bites, rushes, tail strikes, slashes, beam/orb/bolt/wave/ground/meteor effects, knockback and fainting announcements. Move FX sprites and ORAS trainer music come from Pokémon Showdown; Pokémon cries from PokeAPI/cries are bundled for all featured species. Attack sound effects are original type-specific synthesized sounds. All inbound asset URLs are retained in dist/assets/sources.json. This does not recreate frame-by-frame species-specific game animations. No Mega/Primal transformations or army mode yet. Replay repeats battle decisions; cosmetic particles vary.

The default 1× Reel pacing uses short announcements and 1.4–2-second action beats, with extra emphasis on KOs. Duration varies by matchup and seed; it is not artificially fixed. Use Clean 9:16 view and a screen recorder to capture the portrait stage; Escape exits. This mode is not a video exporter. Enable Sound in the header for cries/SFX; the separate music checkbox controls the soundtrack. Pause stops battle motion, active cries and music. Stop returns to team setup.

Install development dependencies with npm install, then npm test for the engine and DOM-driven interface tests. Canvas rendering and audio are mocked in the interface test: it validates flow and replay, not pixel appearance or actual sound playback. Desktop browser QA was unavailable due to a runtime initialization failure.
